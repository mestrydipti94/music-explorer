# 🎵 Music Explorer

Music Explorer is a responsive web application that allows users to search and explore songs using the iTunes Search API. Users can discover music, listen to previews, and save their favourite tracks for later.

## ✨ Features

- 🔍 Search songs by name or artist.
- 🎧 Explore music using the iTunes Search API.
- ▶️ Listen to song previews.
- ❤️ Add songs to favourites.
- 💾 Save favourite songs using Local Storage.
- 🗑️ Clear all favourite songs.
- 📱 Responsive design for different screen sizes.
- ⚡ Loading and error handling.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- iTunes Search API
- Local Storage

## 🌐 API Used

[iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/)
